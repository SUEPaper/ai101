# 机器学习课程教材大纲

## 1. 大纲结论

机器学习课程面向已经完成本站数据科学课程的学习者，采用“在数据科学课中先会用 → 在机器学习课中重新建模与推导 → 用理论解释性质和边界 → 从零实现验证推导”的螺旋式深入结构。基础回归、逻辑回归、PCA 和聚类会再次系统讲解，但不重复 API 和表面直觉，而是回答以下问题：目标函数从哪里来、为什么可以这样优化、解是否唯一、假设何时成立、算法为何收敛、正则化改变了什么、模型会怎样失效。

课程采用“学习问题与优化 → 回归 → 分类 → 神经网络与核心架构 → 非参数模型、树与集成 → 概率模型与潜变量 → 降维与聚类 → 学习理论 → 推荐与强化学习”的主线，不照搬 CMU 10-601、Berkeley CS 189、Berkeley Deep RL 或 Stanford CS229 的原始讲次。建议教材结构为“32 章 + 8 次综合作业 + 1 个结课项目 + 6 个选修数学补充章节”，核心章节约 126–163 小时，结课项目约 12–18 小时；选修补充约 18–26 小时，不计入正式课时与必做考核。

课程内容边界如下：

- Pandas、EDA、SQL 和基础可视化不再重讲；它们作为建模前的数据能力直接使用。
- 线性回归、逻辑回归、梯度下降、正则化、PCA、SVD 和 K-means 会从数学起点完整重建，重点是公式推导、等价解释、优化过程和理论性质。
- 本课程同时系统讲解近邻、决策树、Bagging、随机森林、Boosting、感知机、生成式分类、MLE/MAP、EM、SVM、核方法、PAC/VC 与可靠评价。树、Bagging/随机森林和 Boosting 分成三章，不再压缩在一章集成学习中。
- 神经网络部分讲多层感知机、反向传播，并分别用一章讲清 CNN、RNN、Transformer 的数学结构与最小实现。深度学习课再系统展开现代架构变体、大规模训练、LLM、自监督学习和生成模型。
- 推荐系统从缺失的用户—物品矩阵出发，推导带偏置的低秩分解、显式/隐式反馈目标和成对排序损失，同时讲清冷启动、曝光偏差与反馈回路。
- 强化学习覆盖 MDP、Bellman 方程、动态规划、Monte Carlo/TD、SARSA/Q-learning、DQN、策略梯度与 Actor–Critic。模型式 RL、离线 RL、多任务 RL 和 LLM RL 作为延伸路线，不挤压基础推导。
- 部署、服务化、实验追踪、模型监控和 MLOps 留给机器学习实践课。

课程的数学标准是“重要结论必须知道从哪里来”。正文不要求每个学生都掌握测度论或严格统计渐近理论，但核心算法至少完成以下闭环：

1. 写出建模假设和符号。
2. 从假设得到损失函数或似然。
3. 推导目标函数对参数的梯度、闭式解或迭代更新。
4. 解释可辨识性、凸性、收敛性或复杂度中的关键性质。
5. 用数值实验和从零实现验证公式。
6. 分析假设破坏时算法会怎样失败。

## 2. 目标学习者与先修能力

目标学习者已经能够使用这些算法完成基础任务，但不假设已经理解完整推导。学习者应当能够：

- 使用 Python、NumPy、Pandas、Matplotlib 和 scikit-learn 完成基础数据分析。
- 理解训练集、验证集、测试集、交叉验证和常见分类评价指标。
- 使用线性回归、逻辑回归、梯度下降、正则化、PCA 和 K-means，并理解它们在数据科学流程中的基本用途。
- 使用向量和矩阵表达数据，理解均值、方差、协方差、条件概率和常见随机变量。

课程不设置必修数学桥接单元。需要的数学在算法首次使用时就地补充，并立即用于推导：

- 在线性回归中讲列空间、正交投影、矩阵求导、秩和伪逆。
- 在逻辑回归与生成式模型中讲似然、条件概率、Hessian、熵和交叉熵。
- 在 SVM 中讲约束优化、Lagrange 乘子、对偶和 KKT 条件。
- 在 PCA 中讲二次型、特征值分解、SVD 和 Lagrange 乘子。
- 在 EM 中讲 Jensen 不等式、KL 散度和 ELBO。
- 在 RNN 与 Transformer 中讲 Jacobian 连乘、矩阵形状和数值稳定性。
- 在推荐系统中讲低秩因子化、带缺失值的矩阵目标和成对似然。
- 在强化学习中讲条件期望、不动点、压缩映射直觉、随机近似和 log-derivative trick。

学生不需要先学完一套抽象数学再接触算法；每个数学工具都以当前算法的问题为入口，并配手算、图形和数值验证。对数学推导希望更深入的学习者，另提供 S01–S06 六个选修补充章节；它们不是核心章节的前置条件，不设必做作业，不进入结课考核。

## 3. 课程学习产出

完成课程后，学习者应能：

1. 把实际问题形式化为输入空间、输出空间、假设空间、损失函数和评价方案。
2. 从几何、优化和概率三个角度推导线性回归，并说明正规方程、梯度下降、Ridge 与 MAP 的关系。
3. 从 Bernoulli 分布和最大似然推导二分类逻辑回归，从 Categorical 分布推导 Softmax 回归。
4. 从最大方差和最小重构误差两种目标推导 PCA，并说明特征值分解与 SVD 的等价关系。
5. 从簇内平方和推导 K-means 的交替最小化步骤，并说明它与 GMM、EM 的联系和区别。
6. 从零实现并解释 kNN、决策树、Bagging/随机森林、AdaBoost、感知机、逻辑回归、GMM-EM、PCA、K-means 和简单神经网络的核心步骤。
7. 使用 MLE、MAP、经验风险最小化、正则化和最大间隔统一解释常见学习算法。
8. 判断目标函数的凸性、解的存在性与唯一性，推导常用梯度并执行数值梯度检查。
9. 比较生成式与判别式、参数模型与非参数模型、线性模型与非线性模型的假设和代价。
10. 使用偏差—方差、PAC/VC、学习曲线、校准和统计比较解释泛化与模型选择。
11. 推导卷积的参数共享与反向梯度、RNN 的时间展开与 BPTT、自注意力的缩放点积与矩阵形状，并实现三个最小算子。
12. 从观测评分与隐式反馈推导矩阵分解和成对排序目标，实现最小推荐器并识别离线评价偏差。
13. 从 MDP 定义推导 Bellman 期望/最优方程，证明动态规划更新的关键性质，并实现策略迭代与价值迭代。
14. 推导 TD、Q-learning、策略梯度和 Actor–Critic 的更新，解释有偏/无偏、方差、on-policy/off-policy 与函数近似之间的取舍。
15. 为监督预测、推荐或强化学习任务建立多个合理基线，并用理论假设、实验证据和失败案例说明最终选择。

## 6. 每章统一写作模板

每章页面采用以下结构，保证初学者可以独立学习：

1. 一个可观察的问题，而不是先给算法定义。
2. “你已经会什么”：明确连接数据科学课知识。
3. 预计用时、先修知识和 3 道诊断题。
4. 3–5 个可验证学习目标。
5. 先用图形或具体样本建立直觉。
6. 给出模型假设、输入输出和目标函数。
7. 说明目标函数从哪个概率假设、几何目标或决策原则得到。
8. 不跳步地推导核心公式、梯度、闭式解或迭代更新；核心推导默认展开。
9. 单独列出解的存在性、唯一性、凸性、收敛性或可辨识性条件。
10. 用 NumPy 实现最小版本，并让每一行代码能对应到公式。
11. 用有限差分、数值等价或模拟实验验证推导。
12. 用 scikit-learn 或 PyTorch 对照，不用库调用代替原理讲解。
13. 一个把公式、几何和训练状态联动起来的交互实验。
14. 三次“停下来推一推”与 5–8 道即时反馈题。
15. 一个 30–60 分钟推导与代码练习，依次提供思路、公式骨架、代码骨架和答案。
16. 常见误解、数值问题、反例和调试清单。
17. 本章假设、优点、局限、时间/空间复杂度和适用场景。
18. 术语卡片、下一章连接和实际参考资料。
19. 案例与素材登记：原始链接、作者/机构、精确页码或小节、许可/授权依据、使用方式（原样节选/独立创作/另行授权改编）、归属文案与待替换状态。

数学内容分三层呈现：

- 第一层回答“它在解决什么问题”，使用图形、类比和小样本，但不以类比代替定义。
- 第二层回答“公式从哪里来、每一项是什么意思”，要求所有学生能跟随推导、手算小例子并实现。
- 第三层回答“为什么成立、条件是什么”，核心定理给出完整证明；需要更高数学背景的延伸证明可以折叠。

## 12. 完成标准

- 32 个正式章节、8 次综合作业和结课项目的目标、正文、练习与评价相互一致；S01–S06 明确标记为不计课时、不设必做作业、不进结课考核的选修补充。
- 神经网络已前移到第 13–17 章；第 01–12 章必须在此前覆盖梯度优化、矩阵表示、正则化、Sigmoid/Softmax、交叉熵和数值稳定性。
- 每章明确连接数据科学课；重复出现的算法必须从应用层提升到假设、推导、性质和失效条件，不能只是换一种措辞重讲 API。
- OLS 至少包含投影、正规方程、MLE、伪逆和 Ridge/MAP 的完整关系。
- 逻辑回归至少包含 Bernoulli 似然、交叉熵、梯度、Hessian、凸性和多分类扩展。
- PCA 至少包含最大方差、最小重构误差、特征值分解和 SVD 四条关系。
- K-means 至少包含目标函数、两步更新推导、单调性、局部最优和 GMM 联系。
- 决策树至少包含信息增益、Gini、CART 分类/回归划分、连续阈值搜索、叶节预测、剪枝和高方差。
- Bagging/随机森林至少包含 Bootstrap、平均相关估计器方差推导、特征随机子集、去相关、OOB 误差和特征重要性偏差。
- Boosting 至少包含加性模型、指数损失到 AdaBoost 的完整推导、样本/弱学习器权重、间隔解释、Gradient Boosting 函数梯度视角和噪声敏感性。
- CNN 至少包含局部连接、参数共享、输出尺寸、感受野、平移等变性和卷积前后向。
- RNN 至少包含序列分解、时间展开、BPTT、梯度消失/爆炸和门控梯度路径。
- Transformer 至少包含 Q/K/V、缩放点积、Mask、多头注意力、位置编码、矩阵形状和复杂度。
- 推荐系统至少包含偏置基线、正则化矩阵分解、SGD/ALS、显式/隐式反馈、BPR、Top-K 评价、冷启动和曝光偏差。
- 强化学习至少包含 MDP、Bellman 期望/最优方程、策略/价值迭代、MC/TD、SARSA/Q-learning、DQN、策略梯度和 Actor–Critic。
- 每个核心算法同时包含直觉、数学推导、最小实现、数值验证、库用法、复杂度和失败场景。
- 至少完成 20 个核心交互实验，其中 OLS、逻辑回归、决策树、随机森林、Boosting、PCA、K-means、反向传播、卷积、RNN 梯度流、自注意力、推荐矩阵、Bellman backup、Q-learning 和策略梯度实验为必做。
- 所有代码在固定环境和固定随机种子下运行通过。
- 所有手写梯度都有有限差分检查，所有声称等价的实现都有数值对照。
- 不把 CMU、Berkeley 或其他第三方参考文件打包到公开网站。
- 目标学习者不依赖课堂讲解，也能沿页面提示完成核心主线。

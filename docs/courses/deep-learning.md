# 深度学习与大模型

本课程当前处于规划阶段，具体大纲、课时安排和每节内容尚未确认。计划在机器学习课程的 MLP、反向传播、CNN、RNN 和 Transformer 基础上，系统展开现代深度架构、大规模训练、生成模型与大语言模型。

## 计划目标

- 理解现代深度网络的训练机制、规模效应和架构取舍。
- 掌握视觉、序列、生成和多模态任务的基础建模方法。
- 理解自监督预训练、指令微调、检索增强与大模型评估。
- 能够识别大模型应用中的数据、计算、可靠性和安全边界。

## 计划内容

- 现代深度网络架构与训练系统
- 自监督学习与表征学习
- 生成模型与多模态建模
- 大语言模型的预训练、对齐与推理
- 检索增强、工具使用、评估与安全边界

## 计划学习产出

课程完成建设后，学习者应能解释现代深度模型的关键机制，完成一个可复现的训练或大模型应用实验，并对效果、成本和失效条件作出审慎判断。

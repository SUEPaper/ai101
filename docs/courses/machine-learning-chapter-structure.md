# 机器学习教材章节命名与模块划分

## 1. 已确认结论

机器学习教材采用 **10 个模块、32 个正式章节**。章节标题优先使用算法名称或课程领域中通行的标准主题名称，不再把解释性问题作为章节标题。问题驱动仍然保留，但放在章节导语、案例或首屏问题中。

推荐系统和强化学习分别构成独立模块：推荐系统研究用户—物品反馈中的预测与排序，强化学习研究智能体与环境交互中的序贯决策，两者不再合并为同一模块。

## 3. 模块关系

课程主线依次建立学习问题、优化、监督模型、表示学习、概率模型、无监督学习和学习理论。在此基础上，推荐系统与强化学习形成两个独立的应用与决策方向：

```text
学习与优化
    ↓
线性回归
    ↓
分类与核方法
    ↓
神经网络
    ↓
非参数与集成学习
    ↓
概率模型与潜变量
    ↓
降维与聚类
    ↓
学习理论
    ├── 推荐系统
    └── 强化学习
```

模块九只包含第 29 章，集中讲解显式反馈、隐式反馈、矩阵分解、排序目标与推荐评价。模块十包含第 30–32 章，依次建立 MDP 与动态规划、价值学习、策略学习三条强化学习基础主线。

## 4. 选修数学工具箱

数学工具箱继续独立于 32 个正式章节，不计入核心模块编号：

| 编号 | 章节名称 |
|---:|---|
| S01 | 矩阵分解 |
| S02 | 矩阵微分 |
| S03 | 概率统计 |
| S04 | 信息论 |
| S05 | 凸优化 |
| S06 | Lagrange 对偶 |

核心章节在公式第一次出现时仍需提供足以完成推导的数学说明，不能要求学习者先完成全部数学工具箱。

## 5. 章节命名规则

1. 有明确算法名称时，直接使用算法名称，例如“逻辑回归”“决策树”“期望最大化算法（EM）”。
2. 一章包含紧密关联的多种算法时，列出主要算法，例如“SARSA 与 Q-learning”。
3. 章节讲解标准理论主题而不是单一算法时，使用领域通行名称，例如“泛化、偏差—方差与模型选择”。
4. 中英文缩写只在有助于识别课程与论文术语时保留，例如 OLS、CNN、PAC 和 BPR。
5. 不在标题中使用“为什么”“怎样”等解释性问句；这类问题移到章节导语。
6. 课程目录、页面标题、章节首屏、前后章导航和教材大纲最终必须使用同一名称。

## 6. 后续执行方式

教材正文按第 01 章到第 32 章逐章细化。每章完成后单独核对标题、推导、示例、交互实验、自测题、参考资料、前后章导航和移动端呈现，再进入下一章，避免对全部章节进行只改变外观的批量模板替换。

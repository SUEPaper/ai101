# 数值计算方法训练

《数值计算方法训练》是一门信息与计算科学专业的专业实践课程。课程内容包括 Python 程序设计、基于 Python 实现数值分析中所学计算方法、实验大作业、报告撰写及答辩汇报。

通过课程学习，学生将得到数学建模、程序设计、分析数值结果、写实验报告等环节的综合训练，加深对计算方法的理解，培养应用计算机技术解决工程科学计算问题的能力。

在 AI101 中，本课程提供 Python、NumPy、Matplotlib 与数值计算实践基础，可与[数据科学](./data-science.md)和[机器学习](./machine-learning.md)搭配学习。已掌握 Python 基础的学习者可直接进入数值实验，需要补充工具用法时再查阅相应教程。

:::tip 开始学习
请先阅读[实验 0：预学习](./numerical-computing/labs/index.md)，完成开发环境准备与必读材料，再按顺序完成实验 1–8。
:::

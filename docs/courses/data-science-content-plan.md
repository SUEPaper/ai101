# 数据科学课程网站自学内容建设计划

## 1. 建设结论

数据科学部分以 `ref/ds101/slides` 中的 26 份 PPT 为课程主线，保持讲次、知识顺序和主题边界与 Berkeley Data 100 基本一致；以 `ref/ds101/textbook` 中的教材为补充阅读和案例索引；面向只有基础 Python 经验的学习者，额外建设预备知识、中文原创讲解、原创图解、交互实验、即时反馈题和代码练习。

课程结构采用“1 个预备单元 + 26 讲数据科学主线 + 3 讲图像数据桥接模块 + 1 个结课项目”，预计总学习时间为 61–78 小时。图像桥接模块不改变 Berkeley Data 100 对齐主线；它为继续学习机器学习 CNN 与深度学习计算机视觉的学习者建立统一的数据接口。

这里的“对齐 Berkeley Data 100”是指对齐课程主题、知识边界和学习顺序，不是逐句翻译、复制页面或复刻原有图表。教材与 PPT 的公开使用必须分别完成版权确认。

## 2. 目标学习者与内容缺口

目标学习者已经具备以下能力：

- 能读写基础 Python 代码。
- 理解变量、条件、循环、函数、列表和字典。
- 能安装或使用一个现成的 Python/Jupyter 环境。

Berkeley 教材默认读者已经掌握 Pandas 数据操作、基础概率、抽样、Bootstrap、回归、分类、偏导、梯度、向量和矩阵代数。这个门槛明显高于本课程的目标学习者，因此不能直接把教材章节转换成网页。

网站需要补充两类桥接内容：

- 统一的预备单元：Jupyter、NumPy、Pandas 思维、概率和线性代数速查。
- 就地出现的知识桥：在第 09、12、13、17、22、24 讲重新解释本讲所需的数学知识。

## 4. 预备单元

预备单元不系统重讲 Python，只补齐 Data 100 主线真正需要的能力：

- Jupyter Notebook 的运行顺序、内核状态和调试方式。
- List、Dictionary、函数和 Lambda 的快速复习。
- NumPy 数组、形状、广播和布尔数组。
- 从 Python 容器过渡到 `Series` 和 `DataFrame`。
- 均值、方差、概率分布和条件概率的直觉。
- 向量、矩阵乘法、点积、范数和投影。
- 导数、偏导、梯度和下降方向。
- 20 分钟诊断测试，根据结果推荐对应的补习页。

概率和线性代数内容还需要在相关讲次中再次提供短版解释，避免学习者在正式使用时已经遗忘。

## 5. 每讲页面模板

每一讲对应一个独立页面，并使用统一结构：

1. 本讲要解决的问题。
2. 预计用时、先修知识和诊断题。
3. 3–5 个可验证的学习目标。
4. 核心概念图解。
5. 按 PPT 顺序组织的中文原创讲解。
6. 可运行的最小代码示例。
7. 一个交互实验。
8. 三次“停下来想一想”。
9. 5–8 道即时反馈题。
10. 一个 15–30 分钟代码练习。
11. 常见错误与调试提示。
12. 本讲小结、术语卡片和下一讲预告。
13. PPT 与教材对应阅读入口。

数学内容采用三层呈现：

- 第一层：直觉、图形和实际问题。
- 第二层：公式含义和代码实现。
- 第三层：推导过程，默认折叠，供希望深入的学习者查看。

代码练习采用逐级提示：

- 第一次只显示任务。
- 第二次显示解题思路。
- 第三次显示代码骨架。
- 完成或主动放弃后才能查看参考答案。

## 7. 图片建设方案

图片只用于解决学习障碍，不建设与知识内容无关的装饰性配图。优先建设以下四类：

- 数据结构图：DataFrame、Index、GroupBy、Join、设计矩阵。
- 过程动画：生命周期、Bootstrap、K-fold、梯度下降、K-means。
- 几何图解：残差、向量投影、决策边界、PCA。
- 对比图：正确与错误可视化、MSE 与 MAE、L1 与 L2、ROC 与 PR。

每讲至少提供 2 张原创教学图，数学密集章节至少提供 4 张。所有图片保留可编辑源文件，统一颜色、符号和术语，不直接把 PPT 截图作为网页正文。

## 8. 网站交互技术方案

当前项目是静态 VitePress 网站，交互学习采用两层方案。

代码实验放在独立的 JupyterLite 区域，并按需加载浏览器 Python 环境。不要让每个课程页面都加载 Pyodide。

- 1 个 15–30 分钟代码练习。
- 1 个开放思考题。

每个模块增加一次综合作业：

1. Pandas 数据整理作业。
2. EDA 与可视化报告。
3. 回归与模型评估作业。
4. 抽样和 Bootstrap 实验报告。

## 10. 版权与许可证边界

### 10.1 CC BY-NC-ND 4.0 不允许公开分享翻译版本

`CC BY-NC-ND 4.0` 中：

- `BY` 要求署名。
- `NC` 限制商业使用。
- `ND` 禁止公开分享改编作品。

协议把翻译、修改、重新编排或其他需要版权人许可的变换归入 `Adapted Material`。4.0 版本允许为非商业目的制作和保存改编内容，但不允许 `Share` 这些改编内容。公开课程网站属于公众可以自行访问的传播场景，因此属于 `Share`。

所以，“只要标注来源，就可以公开发布中文翻译和拓展版本”这个理解不成立。署名只能满足 `BY`，不能解除 `ND` 的限制。

- [CC BY-NC-ND 4.0 Deed](https://creativecommons.org/licenses/by-nc-nd/4.0/)

### 10.2 可以采用的方式

- 在非商业条件下原样分享教材，并按协议完整署名、保留许可证说明和原始链接。
- 链接到原始教材，而不是把它翻译后重新发布。
- 把未修改的原始作品与独立创作的内容作为合集呈现，但必须清晰区分两者，不能把翻译或改写伪装成独立附注。
- 基于相同事实、概念和教学目标重新创作中文课程，使用自己的措辞、结构、案例、图表、题目和交互，并注明 Berkeley Data 100 和教材是课程设计参考。
- 向权利人取得单独的书面许可，明确允许中文翻译、改编、公开发布及可能的商业使用。
- 在适用法律明确允许的合理使用或其他版权例外范围内进行有限引用；是否适用需要结合发布地区、引用比例和用途单独判断。

### 10.3 参考思路后独立创作的边界

版权保护具体的文字、图画和其他原创表达，不保护事实、思想、数学原理、教学方法、系统或操作流程。因此，可以学习原教材讲授 DataFrame、Bootstrap、回归、PCA 等知识的思路，再围绕相同知识点独立编写中文教材。

“从零开始写”需要以最终成果是否形成独立表达来判断，而不只取决于写作时是否新建了空白文件。即使没有直接复制粘贴，逐段对应的翻译、近义改写、只更换颜色的图表或保留相同故事和数值的练习，仍然可能过于接近原作品。

可以采用：

- 学习原课程的知识范围、教学目标和概念关系。
- 讲解相同的公共知识、事实、公式、算法和软件 API。
- 参考总体主题顺序，再根据目标学习者重新设计模块和知识桥。
- 使用自己的语言、案例、数据、图表、练习和交互实验。
- 在参考资料中说明课程设计受到 Berkeley Data 100 和原教材启发。

避免采用：

- 对原文逐句翻译或按照段落进行近义改写。
- 复刻原教材具有独创性的章节结构、叙事顺序和解释方式。
- 重画原图但只改变颜色、字体、标签或局部布局。
- 复制原练习的故事、数据、设问结构和参考答案。
- 把标注来源视为复制受保护表达的充分许可。

每一讲按照以下流程编写：

1. 阅读相关 PPT 和教材章节，提炼本讲需要掌握的事实、概念、方法和学习难点。
2. 关闭原始材料，从学习目标出发重新编写中文提纲。
3. 选择适合中国 Python 初学者的新案例和新数据。
4. 独立编写正文、代码、图解、练习、答案和交互实验。
5. 与原材料进行相似性复核，删除过于接近的措辞、图形构图、案例和题目。
6. 在“参考资料”区记录实际参考的课程、章节、作者、链接和许可证。

# 深度学习与大模型课程章节命名与模块划分

## 1. 已确认结论

课程采用 **16 周、6 个模块、32 个正式章节、8 次综合作业和 1 个结课项目**。课程接续数据科学课 V1–V3 与机器学习课第 13–17 章，不重复讲解图像数组和 OpenCV 基础、MLP、反向传播、卷积的局部连接与参数共享、RNN 时间展开和自注意力基础推导。

课程从现代训练与经典深层架构开始，依次进入计算机视觉、生成模型、NLP 基础、大语言模型和 GPU/AI Infra。GPU 与 AI Infra 不是附录，而是解释大模型训练成本、算子效率、分布式执行和在线服务行为的正式模块。

## 3. 模块关系

课程主线不是模型名称的罗列，而是从训练稳定性逐步走向表示、生成、规模化和服务：

```text
现代训练方法
    ↓
视觉架构与密集预测
    ↓
生成模型
    ↓
文本表示与语言模型
    ↓
大模型预训练、后训练与应用
    ↓
GPU 算子、分布式训练与推理服务
```

计算机视觉模块把 CNN 作为已知算子，重点研究架构为何从 AlexNet 演进到 ResNet、ViT 和 Swin，以及分类表示如何进入检测和分割。大语言模型模块把自注意力作为已知机制，重点研究预训练目标、现代块结构、数据与计算规模、后训练、检索、Agent、评估和失效条件。

| 编号 | 对应章节 | 作业主题 | 可验证产出 |

| A1 | 01–03 | AdamW 与训练系统消融 | 固定预算比较优化器、调度、归一化和混合精度，提交可复现实验账本 |
| A2 | 04–05 | ResNet 分类与迁移学习 | 完成残差网络训练、冻结/解冻策略和分布外切片诊断 |

| A4 | 10–11 | ViT、Swin 与视觉表征 | 比较 patch、窗口、位置表示和预训练策略对精度与成本的影响 |
| A5 | 12–15 | GAN 与现代生成模型 | 复现模式坍缩或训练不稳，并用 FID/样本覆盖等证据分析改进 |

| A8 | 29–32 | GPU 算子与推理服务 | 完成一个算子基准和 vLLM/SGLang 服务基准，报告 TTFT、TPOT、吞吐与显存 |

## 5. 章节命名规则

1. 有标准模型或系统名称时直接使用通行名称，不发明新的中文缩写。
2. 同一章只合并具有清晰演进关系或共同问题定义的模型。
3. “基础”只用于确实建立新数据接口的 NLP 模块，不重新包装机器学习课已讲内容。
4. GPU、算子和服务系统使用同一套性能术语：延迟、吞吐、显存、带宽、算力和利用率必须区分。
5. 课程目录、章节首屏、作业映射、来源登记和前后章导航必须使用同一名称。

## 6. 实施顺序

正文按 01–32 章逐章建设。每章完成后单独核对概念边界、公式、代码、实验、测验、论文引用、硬件假设与移动端呈现，再进入下一章。不能先批量生成同构页面，再把缺少证据的目录状态标成“已完成”。

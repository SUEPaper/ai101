# 人工智能实践课

本课程当前处于规划阶段，具体大纲、课时安排和每节内容尚未确认。计划把数据科学、机器学习以及后续深度学习与大模型课程中的能力，接入可运行、可复现、可监控的工程交付流程。

## 计划目标

- 能够把业务或研究问题转化为可验收的人工智能任务。
- 掌握数据、代码、模型和实验的版本管理与追溯方法。
- 建立从离线评估到服务化、监控和迭代的完整交付链路。
- 能够说明系统的性能、成本、可靠性、安全边界和回退方案。

## 计划内容

- 项目选题与问题定义
- 数据集构建与版本管理
- 训练脚本、实验记录与指标跟踪
- 模型误差分析与迭代优化
- 服务化、部署、监控与 MLOps
- 项目展示、验收报告与运行手册

## 计划学习产出

课程完成建设后，学习者应能交付一个包含问题定义、数据与模型制品、评估证据、部署方式、监控方案和复现步骤的人工智能系统。

# 八次综合作业

八次作业不是章节末小题的加长版。每次都要求完成“假设 → 推导 → 从零实现 → 数值验证 → 失败分析”闭环，并保留可复现随机种子、环境说明和结果表。

## 统一提交规范

每次提交一个 Notebook 和一份不超过 6 页的推导说明。Notebook 必须从头运行成功；核心算子只用 NumPy，scikit-learn 或 PyTorch 只用于数值对照。每个结论标注来自公式、实验还是外部资料。

| 评分项 | 权重 | 达标证据 |
|---|---:|---|
| 建模与符号 | 15% | 输入、输出、假设、损失、分布假设和形状完整 |
| 推导 | 30% | 关键等式不跳步，说明每步所用条件 |
| 实现 | 25% | 公式与代码逐项对应，边界输入有检查 |
| 数值验证 | 15% | 有限差分、等价实现或单调性断言 |
| 失效分析 | 15% | 至少一个可复现反例，并解释原因而非只调参 |

## A1 · OLS、Ridge 与数值线性代数

1. 从残差正交和高斯 MLE 两条路径推导 OLS。
2. 实现正规方程、`lstsq`/SVD 伪逆和梯度下降三种求解器。
3. 证明 $H=X(X^TX)^{-1}X^T$ 对称且幂等；数值检查 $X^Te=0$。
4. 从惩罚形式推导 Ridge 闭式解，并画出各特征值方向的收缩率 $s_j/(s_j+\lambda)$。
5. 构造完全共线、近共线和重尾噪声三个失败场景，比较系数、预测和条件数。

验收断言：满列秩小数据上三种 OLS 预测一致；伪逆在秩亏时仍给出最小范数解；$\lambda$ 增大时训练 SSE 不减、系数范数不增。

## A2 · 逻辑回归与 Softmax

从 Bernoulli/Categorical 似然推出二分类和多分类交叉熵，推导梯度、Hessian 与矩阵形状。实现稳定 `sigmoid`、`logsumexp`、损失和优化器，并用中心有限差分检查每个参数。

必须比较完全分离、有/无 L2 正则、类别不平衡和代价敏感阈值。报告概率校准与固定 0.5 阈值的区别。

## A3 · SVM 与核方法

从几何间隔推出硬间隔原始问题，再加入松弛变量得到软间隔；写出 Lagrangian，对 $w,b,\xi$ 取驻点，消元得到对偶，并逐条核对 KKT 条件。

实现线性、多项式和 RBF Gram 矩阵，数值检查对称与半正定。比较逻辑回归、线性 SVM 和核 SVM 的间隔、概率语义、训练/预测复杂度，以及 $C,\gamma$ 的联合影响。

## A4 · MLP 与三种核心架构

- 手推两层 MLP 对 $W_1,b_1,W_2,b_2$ 的全部梯度，处理分支梯度累加。
- NumPy 实现前向/反向并完成相对误差小于 $10^{-6}$ 的梯度检查。
- 实现小型二维互相关的输入与卷积核梯度。
- 展开三步 RNN 并实现 BPTT，记录 Jacobian 连乘与梯度范数。
- 实现带因果 Mask 的单头自注意力，与 PyTorch 结果对照。

所有张量必须在推导与代码旁标注形状；不得用 Autograd 代替核心反向实现。

## A5 · kNN、决策树与集成

从零实现深度受限 CART、Bagging、随机森林和 AdaBoost。推导分类 Gini/信息增益、回归 SSE 下降、相关估计器平均方差和 AdaBoost 的 $\alpha_t$、样本权重更新。

在固定数据生成过程中重复抽样至少 100 次，分离比较 kNN、单树、Bagging、随机森林与 Boosting 的偏差、方差和稳定性；验证 OOB 样本比例接近 $36.8\%$。

## A6 · GMM-EM、PCA 与 K-means

1. 从最大方差与最小重构误差两条路径推导 PCA，证明与 SVD 的关系。
2. 实现 PCA 并与 `np.linalg.svd` 对照，检查投影矩阵幂等。
3. 推导 K-means 分配/更新步并记录每轮簇内平方和不增。
4. 从 ELBO 推导 GMM-EM，使用 log-sum-exp 计算责任度，记录观测对数似然不减。
5. 用非球形簇、不同密度与多个初值比较硬分配和软分配的失败方式。

## A7 · 推荐系统

实现全局均值、用户/物品偏置、带偏置矩阵分解和 BPR 四条基线。推导显式反馈平方损失的 SGD 与 ALS 更新，以及 BPR 成对 logistic 似然的梯度。

评价必须按时间或用户划分，报告 RMSE 与 Recall@K/NDCG@K 的不同含义；构造曝光偏差，说明“未观测不是 0 分”；分析冷启动、流行度偏置和反馈回路。

## A8 · 强化学习

在同一个小型 Gridworld 中完成：策略评价、策略迭代、价值迭代、Monte Carlo、SARSA、Q-learning、REINFORCE 与带 baseline 的 Actor–Critic。

要求：

- 从 MDP 定义推导 Bellman 期望/最优方程并验证 residual 收缩。
- 比较 SARSA 与 Q-learning 在有探索风险时的路径。
- 用多个种子报告回报均值、标准差和学习曲线置信带。
- 数值验证 baseline 不改变平均策略梯度方向，却降低估计方差。
